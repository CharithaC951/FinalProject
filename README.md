A full-stack recipe application designed to preserve and present traditional home-style recipes with a modern web interface.

## ✨ Features

Dynamic recipe cards with images and descriptions

Expand/Collapse and detailed recipe views

Ingredients, instructions, cooking time, and serving size

Personal “memory” section for each recipe

Responsive and clean UI built with Vue.js

## 🛠️ Tech Stack

Frontend: Vue.js, HTML, CSS, JavaScript

Backend: Node.js

Database: MongoDB

Architecture: RESTful APIs, component-based frontend design

This project demonstrates full-stack development skills, clean UI design, backend API development, and real-world data modeling using MongoDB.
